# Планировщик задач

Веб-сервер — аналог TODO-листа. Задачи хранятся в SQLite, файл `scheduler.db`
создаётся автоматически при первом запуске. Задачи можно добавлять, редактировать,
удалять и отмечать выполненными. Если у задачи задано правило повторения
(`d 5` — через 5 дней, `y` — каждый год), то при выполнении она переносится на
следующую дату, обычная задача при выполнении удаляется.

Фронтенд лежит в директории `web`, тесты в `tests`. Код разбит на три пакета:
`pkg/server`, `pkg/api`, `pkg/db`.

## Задания со звёздочкой

Не выполнялись: правила повторения `w` и `m`, поиск задач по строке,
аутентификация, переменные окружения `TODO_PORT` и `TODO_DBFILE`.

## Запуск

```bash
go mod tidy
go run .
```

Сервер слушает порт 7540, в браузере нужно открыть http://localhost:7540/

## Тесты

Сначала запустить сервер, затем из корня проекта:

```bash
go test ./tests
```

Можно запускать по одному тесту, например `go test -run ^TestAddTask$ ./tests`.
В `tests/settings.go` оставлены значения по умолчанию: `Port = 7540`,
`DBFile = "../scheduler.db"`, `FullNextDate = false`, `Search = false`,
`Token = ''`. Если включить `FullNextDate` или `Search`, потребуются задания
со звёздочками, которые не выполнялись.
